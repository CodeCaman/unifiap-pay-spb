🧪 Testar Sistema PIX

Execute o comando abaixo para testar uma transação PIX:

curl -X POST http://localhost:30050/pix \ -H "Content-Type: application/json" \ -d '{"chave_pix":"11888888888","valor":10.50,"descricao":"Teste sistema"}'

Ou use o arquivo de teste:

curl -X POST http://localhost:30050/pix \ -H "Content-Type: application/json" \ -d @test-pix.json

🔧 Comandos Úteis

Ver status dos pods:

kubectl get pods -n unifiapay

Ver logs da API:

kubectl logs -n unifiapay -l app=api-pagamentos-simple --tail 50

Ver logs da Auditoria:

kubectl logs -n unifiapay -l app=auditoria-simple --tail 50

Reiniciar serviços:

kubectl rollout restart deployment -n unifiapay
